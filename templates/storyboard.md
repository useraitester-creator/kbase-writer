# Сценарий иллюстраций

Прежде чем снимать интерфейс, заполните таблицу по реальным действиям пользователя.
Идентификаторы должны совпадать с `shots[].id` в `capture.json`.

| ID кадра | Задача читателя | Состояние / действие | Область интерфейса | Подпись |
|---|---|---|---|---|
| 01-start | Понять, с чего начать | Исходный экран | Основная форма | Где начинаем работу |
| 02-result | Проверить результат | Завершённое действие | Карточка результата | Что должно появиться |

Для каждого кадра проверьте точность текста кнопок, демонстрационный характер
данных и читаемость снимка в размере страницы статьи. Строки выше — пример
структуры: замените их сценарием своего приложения.
