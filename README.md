# Kbase Writer 2.0

Умение для пользовательских статей по Битрикс24: сценарий → скриншоты настоящего
интерфейса → Markdown → Word со встроенными изображениями.

## Как работать

Установите репозиторий как умение `kbase-writer` через установщик вашего агента
или поместите его целиком в `.agents/skills/kbase-writer` проекта. В корне умения:

```sh
npm ci
```

Нужны Node.js 22.12+ и Python 3. Puppeteer загружает Chrome при установке;
в Linux также нужны системные библиотеки для запуска браузера.

Дайте агенту задачу:

> Используй kbase-writer. Подготовь статью по этому приложению для сотрудников.
> Проверь названия кнопок, составь сценарий, сними настоящий интерфейс на
> вымышленных данных. Сохрани статью, изображения и Word в out/instruction/.

Агент читает `SKILL.md` и `AGENTS.md`, изучает приложение и готовит материал.
Для обновления статьи укажите существующий файл и изменившийся сценарий.

## Команды

Запускаются из корня установленного умения; пути ведут к материалам вашего проекта:

```sh
# После подготовки локального стенда и capture.json:
npm run capture -- /path/to/project/out/instruction/capture.json

# Из готовой статьи с локальными PNG:
npm run word -- /path/to/project/out/instruction/article.md /path/to/project/out/instruction/article.docx

# Проверка контейнера, XML и ссылок на ресурсы:
npm run check:word -- /path/to/project/out/instruction/article.docx --expect-images 9
```

Число `9` замените числом снимков вашей статьи. Для контейнера, где sandbox Chrome
недоступен, к команде съёмки добавьте `--no-sandbox`.

В Word сохраняются заголовки, выделения, ссылки, списки, таблицы, советы и PNG.
Картинки в Markdown размещайте отдельными абзацами; пути — внутри папки статьи.
Необязательный третий аргумент экспорта — JSON с `header`, `title`, `subject`,
`creator`, `figures: { maxWidth, maxHeight }` и индивидуальными размерами
`images: { "images/01-screen.png": { "maxWidth": 620, "maxHeight": 520 } }`.
Размеры задаются в пикселях макета. Исходные PNG встраиваются без пересжатия.

Для съёмки нужны собранные компоненты приложения и адаптация состояний:
[как подготовить стенд и сценарий](references/capture.md).
Проверка перед передачей: открыть Word, оценить переносы страниц и читаемость снимков.
Команда проверки подтверждает структуру файла, но не его внешний вид.

Пакет не публикует статьи автоматически. Для загрузки в базу знаний нужны её адрес,
доступное подключение и запрос пользователя. `video-shotcraft` устанавливать не нужно.

## Проверка инструментов

```sh
npm test
# В контейнере без sandbox Chrome:
KBASE_TEST_NO_SANDBOX=1 npm test
```

Происхождение подхода и границы переноса описаны в [references/provenance.md](references/provenance.md).
